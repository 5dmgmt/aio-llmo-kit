# 月次の計測の雛形

月に 1 回、AI 検索での見え方を記録します。このファイルを `docs/aio/YYYY-MM.md`（自分のサイトのリポ）にコピーして、空欄を埋めてください。

AI の回答は、同じ問いでも毎回変わります。1 回の結果で良し悪しを決めず、**数か月ぶんを並べて傾向を見る**ための記録です。画面の写真を残しておくと、後から見比べられます（保管場所は自分で決めます）。

## 2. 固定の問い

自分のお客さまが実際に聞きそうな問いを 6 つ前後決めて、**毎月同じ文面**で入れます。半分は自社の名前を入れない問い（「〇〇の選び方」「〇〇とは」）、半分は自社の名前を入れる問いにすると、見え方の違いが分かります。

引かれたかどうかは、次のどれかを書きます。**頁を引用**（自社の頁が出典として出た）／**言及のみ**（名前は出たが頁は出ない）／**なし**。

| 問い | サービス | 引かれたか | どの頁 | 何と言われたか（要点） |
|---|---|---|---|---|
| 問い 1 | Google（AI Overview） | | | |
| 問い 1 | Google（AI モード） | | | |
| 問い 1 | ChatGPT | | | |
| 問い 1 | Perplexity | | | |

事実と違うことを言われていたら、その頁の記述が足りない可能性があります。頁に書き足す案を起案し、オーナーが決めます。
